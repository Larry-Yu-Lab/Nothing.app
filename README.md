# Nothing. — iOS Swift & WidgetKit Code

Production-ready Swift code for the **Nothing.** iOS app and Home Screen widgets:

## Files:
- **`NothingApp.swift`**: Main application entry point (`@main`).
- **`ContentView.swift`**: Interactive in-app void with Apple Taptic Engine feedback (`UIImpactFeedbackGenerator`), screen time tracker, and Zero Metrics bottom sheet.
- **`NothingWidget.swift`**: WidgetKit extension providing:
  - Small "nothing." widget (minimalist agenda)
  - Small negative space widget (for clean grid layouts)
  - Medium widget (empty calendar agenda)
  - Lock Screen circular and rectangular widgets.
- **`AppIcon_1024x1024.png`**: Apple App Store compliant solid RGB `#000000` icon (no alpha channel).
